# 🎮 坦克大战 Tank Battle

一个使用HTML5 Canvas和原生JavaScript开发的完整网页版坦克大战游戏。

## 📋 游戏特性

### 核心功能
- ✅ 玩家坦克控制（方向键移动，空格键发射）
- ✅ 敌方AI坦克（自动移动和智能射击）
- ✅ 子弹发射系统和碰撞检测
- ✅ 可破坏的砖墙和坚不可摧的钢墙
- ✅ 基地保护目标
- ✅ 完整的得分系统和生命值显示
- ✅ 游戏胜利/失败判定
- ✅ 关卡系统（难度递增）
- ✅ 暂停功能

### 技术实现
- 🎨 HTML5 Canvas进行游戏渲染
- 💻 原生JavaScript实现所有游戏逻辑
- 🎯 精确的碰撞检测算法
- 🤖 智能敌方AI（自动寻路、射击）
- 🎬 流畅的游戏循环和帧动画
- 📱 响应式设计，适配不同屏幕尺寸
- 🎨 现代化的UI设计和渐变效果

## 🎯 游戏目标

1. **消灭所有敌方坦克** - 每关需要击败一定数量的敌人
2. **保护基地** - 绿色基地被摧毁则游戏失败
3. **保持生命值** - 生命值归零则游戏结束
4. **通关进阶** - 完成每关后进入更高难度

## 🕹️ 游戏操作

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动坦克 |
| Space | 发射子弹 |
| P | 暂停/继续游戏 |

## 🎨 游戏元素

- 🟦 **玩家坦克（蓝色）** - 你控制的坦克
- 🟥 **敌方坦克（红色）** - AI控制的敌人
- 🟨 **子弹（黄色）** - 坦克发射的弹药
- 🟫 **砖墙（棕色）** - 可被子弹摧毁的障碍物
- ⬛ **钢墙（灰色）** - 坚不可摧的墙体
- 🟩 **基地（绿色）** - 必须保护的目标

## 🚀 如何运行

### 方法1：直接打开
1. 将所有文件保存到同一目录
2. 双击 `index.html` 在浏览器中打开
3. 开始游戏！

### 方法2：使用本地服务器
```bash
# 使用Python 3
cd tank-game
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server

# 然后访问 http://localhost:8000
```

## 🎮 游戏机制详解

### 玩家系统
- 初始生命值：3
- 移动速度：3像素/帧
- 射击冷却：500毫秒

### 敌方AI
- 移动速度：2像素/帧
- 自动寻路：30%概率向玩家方向移动
- 射击间隔：2000毫秒
- 碰撞处理：撞墙或边界自动转向

### 关卡系统
- 第一关：5个敌人
- 每关递增：+2个敌人
- 同屏最大敌人数：3个
- 通关奖励：+500分

### 得分规则
- 击毁敌方坦克：+100分
- 完成关卡：+500分

### 碰撞检测
- 矩形碰撞检测算法（AABB）
- 精确的子弹碰撞判定
- 坦克与墙体、基地的碰撞

## 🎨 代码结构

### 核心类

#### `Tank` 类
- 玩家和敌方坦克的基类
- 包含移动、旋转、射击功能
- AI行为逻辑

#### `Bullet` 类
- 子弹实体
- 方向性移动
- 碰撞检测

#### `Wall` 类
- 墙体障碍物
- 可破坏/不可破坏类型
- 不同的视觉效果

#### `Base` 类
- 基地实体
- 被击中判定
- 摧毁状态显示

#### `Game` 类
- 游戏主控制器
- 游戏循环管理
- 状态管理
- UI更新

## 🔧 配置参数

所有游戏参数都在 `GAME_CONFIG` 对象中定义，可轻松调整：

```javascript
const GAME_CONFIG = {
    CANVAS_WIDTH: 800,           // 画布宽度
    CANVAS_HEIGHT: 600,          // 画布高度
    TANK_SIZE: 30,               // 坦克大小
    BULLET_SIZE: 6,              // 子弹大小
    BULLET_SPEED: 5,             // 子弹速度
    PLAYER_SPEED: 3,             // 玩家速度
    ENEMY_SPEED: 2,              // 敌人速度
    FIRE_COOLDOWN: 500,          // 射击冷却（毫秒）
    ENEMY_FIRE_INTERVAL: 2000,   // 敌人射击间隔
    INITIAL_LIVES: 3,            // 初始生命值
    ENEMIES_PER_LEVEL: 5,        // 每关敌人基础数量
    MAX_ENEMIES_ON_SCREEN: 3     // 同屏最大敌人数
};
```
